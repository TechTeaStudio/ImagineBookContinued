# Vault Map

Where things live in the ImagineBook Continued vault. Skim this before creating a note, and prefer updating an existing note over adding a new one.

## Project at a glance

- **Name:** ImagineBook Continued, mod id `imaginebook`, a maintained fork by Tech Tea Studio.
- **Lineage:** ImagineBook by JavaJumper and Riflusso (https://github.com/JumperOnJava/ImagineBook), through the Minecraft 26.x port by Bratik17078 (https://github.com/Bratik17078/ImagineBook). `fabric.mod.json` lists JavaJumper and Riflusso as authors, Bratik17078 and Tech Tea Studio as contributors.
- **What it does:** adds images to book and quill and written books. An image is a text tag on the page, `[link,x,y,width%,height%,rotation]`. Since 1.3.1.0 the editor stores a web link as a code, `imgur:<id>` or `u:<base64url>`, so the book holds no web address; plain `http:` and `https:` links in older books still work, and `res:` takes a resource id. The mod is client-side only; other players who have it (1.3.1.0 or later, for codes) see the images, players without it see the tag text.
- **Target:** Minecraft 26.3 (unobfuscated, Mojang names at runtime), Fabric Loader 0.20.1, Fabric API, Java 25. Stendhal is an optional companion mod.
- **Licence:** LGPL-3.0-only (`LICENSE`).
- **Version:** single source is the `VERSION` file (1.3.1.1 now, 1.3.0.0 when this vault was created), odometer style, one digit per part. `VersionDriftTest` holds `build.gradle`, `fabric.mod.json`, `tools/build_local.py` and the newest `CHANGELOG.md` heading to it.
- **Branches:** day-to-day work on `main`, releases on `product`.
- **Distribution:** Modrinth, slug `imaginebook-continued`.

## Conventions

### Frontmatter

Every note carries the studio schema and no other fields:

```yaml
type: project | note | decision | meeting | person | task | concept | index | summary | runbook
status: active | draft | blocked | archived | deprecated
priority: low | medium | high | critical
tags: []
aliases: []
summary: ""
related: []
created: YYYY-MM-DD
updated: YYYY-MM-DD
```

A superseded note gets `status: deprecated`, and its `summary` names the note that replaces it. Bump `updated` on every edit.

### Folder notes

Every folder has a folder note with the same name (`01 Architecture/01 Architecture.md`): a one-line purpose, a Waypoint block, key documents, status and a live Dataview table of the folder's notes.

### Waypoint

Navigation between the `%% Begin Waypoint %%` and `%% End Waypoint %%` markers is generated by the plugin. Never edit inside those markers.

### Writing

- No horizontal rules in note bodies; split sections with `##` and `###` headings.
- No long dashes; use a colon, a comma or a plain hyphen.
- Name the source file in the repository for every claim about behaviour, so a note can be checked against the code.
- Keep notes short: 500 to 1000 words, a project overview up to 1500.

### Plugins

Dataview, Folder notes, Metadata Menu, Obsidian Git, Linter, Omnisearch, Templater, Waypoint. The `.obsidian/` folder was copied from the Oxygen Rocket Calculator vault. Per-machine state (`.obsidian/workspace.json`) is kept out of git by the vault's own `.gitignore`.

### Templates

`00 System/Templates/` holds Note, Decision, Meeting and Runbook. Create notes through Templater and replace every `<% tp.* %>` placeholder before saving.
