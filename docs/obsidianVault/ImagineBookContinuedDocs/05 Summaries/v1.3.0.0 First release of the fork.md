# v1.3.0.0 First release of the fork

## Summary

1.3.0.0 is the first release of ImagineBook Continued, for Minecraft 26.3 on Fabric. It starts from upstream 1.2.9 as ported to Minecraft 26.x by Bratik17078, fixes the crash with Stendhal and three other faults, and narrows the build to one target. `CHANGELOG.md` in the repository is the line-by-line source; this note adds context.

## Starting point: 1.2.9

From `CHANGELOG.md` (upstream and the 26.x port):

- Ported to Minecraft 26.2 and 26.3 (Bratik17078).
- Pasting into the book text area replaces the selection and flows the overflow onto new pages within the vanilla page and book limits (Bratik17078). The logic lives in `util/BookPaste`, pinned by `BookPasteTest`.
- A crash from a function not available on Java 17 fixed upstream.

## Shipped in 1.3.0.0

| Change | Detail | Where |
|---|---|---|
| Fixed: Stendhal crash | Opening a book and quill with Stendhal crashed (`Cannot assign field "visible" because "this.removeButton" is null`). Stendhal cancels `BookEditScreen.init()` at its head, so widgets added at its tail never existed. They are now added after `Screen` has called `init()`, and every use tolerates their absence. | `mixin/ScreenInitMixin`, `compat/BookEditScreenHooks`, `mixin/NewBookEditScreenMixin`; [[Stendhal Compatibility]] |
| Fixed: page button crash | A page button missing from a screen built by another mod no longer crashes a mouse click. | `NewBookEditScreenMixin.mouseClicked` |
| Fixed: hanging downloads | Downloads had no timeout, so one hanging host blocked every later image. Now 10 s connect, 15 s read, and a User-Agent. | `resolvers/AsyncImageDownloader` |
| Fixed: download storm | A failed image was downloaded again on every frame the page stayed open. Retries now wait 30 s, then 60 s, and stop after 3 failures until the game restarts. | `resolvers/RetryPolicy`, `RetryPolicyTest` |
| Removed: other targets | The 1.20 to 1.21 Stonecutter build and the NeoForge and 26.2 targets; only the Fabric 26.3 build ships. They remain in the git history. | [[Single Fabric 26.3 target]] |
| Removed: unused textures | `_error.png`, `_error - Copy.png`, `png_error.png`, `transparent.png`. | `src/main/resources/assets/imaginebook/textures/` |
