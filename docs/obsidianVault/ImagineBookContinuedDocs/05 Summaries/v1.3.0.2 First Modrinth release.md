# v1.3.0.2 First Modrinth release

## Summary

1.3.0.2 is meant to be the first version of ImagineBook Continued on Modrinth. The mod code is the same as 1.3.0.0; the only change fixes the CI Mixin check that stopped 1.3.0.1, which was never tagged or published. Its `CHANGELOG.md` section is written for players, because the publish script sends that section as the Modrinth changelog. `CHANGELOG.md` in the repository is the line-by-line source; this note adds context.

## Shipped in 1.3.0.2

From `CHANGELOG.md`:

> First version published on Modrinth. The mod is the same as 1.3.0.0, which fixed, compared with the 26.x port of ImagineBook 1.2.9:
>
> - the crash when opening a book and quill with Stendhal installed;
> - image downloads that never timed out and blocked every later image;
> - broken image links that were downloaded again on every frame.
>
> Release tooling: fixed the CI Mixin check, which found the smoke mod's `fabric.mod.json` twice and stopped 1.3.0.1 before it was published.

## What stopped 1.3.0.1

- Run: the first CI run on `product`, 2026-11-17, GitHub Actions run 44026021671, commit `5abcf67`, version 1.3.0.1.
- Passed: `./gradlew build` (compile and all JUnit tests) and the release script tests (`python3 -m unittest discover -s tools -p "test_*.py"`).
- Failed: `./gradlew runMixinSmoke`, at task `processSmokeResources`: "Entry fabric.mod.json is a duplicate".
- Cause: `smoke.gradle` added `src/smoke/java` and `src/smoke/resources` to the `smoke` source set with `srcDir`. Those are already the default folders of a source set named `smoke`, so every file was listed twice and the second `fabric.mod.json` failed resource processing. In Bratik17078's multi-project layout the same lines pointed at another folder, so they never failed there.
- Why only CI saw it: the local checks, `tools/build_local.py` and `tools/mixin_smoke.py`, build the smoke mod without Gradle ([[Build and Test]]).

## Fix

- The `srcDir` lines were removed from `smoke.gradle`. The source set now only adds the `main` classpaths, and a comment there records why the defaults are not repeated.
- `CiWorkflowTest.smokeSourceSetUsesGradleDefaultsOnly` (`src/test/java/io/github/jumperonjava/imaginebook/CiWorkflowTest.java`) fails if `smoke.gradle` contains `srcDir`, and checks that `src/smoke/resources/fabric.mod.json` and `src/smoke/java` exist.
