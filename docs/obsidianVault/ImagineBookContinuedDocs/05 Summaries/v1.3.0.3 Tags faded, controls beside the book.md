# v1.3.0.3 Tags faded, controls beside the book

## Summary

1.3.0.3 fixes the two faults the owner found when testing 1.3.0.2 in game with Stendhal 1.4.9 on 2026-11-17: image tag text drawn over the picture, and ImagineBook's controls covering Stendhal's formatting toolbar. The same test confirmed the Stendhal crash fix. `CHANGELOG.md` in the repository is the line-by-line source; this note adds context.

## Shipped in 1.3.0.3

From `CHANGELOG.md`:

> - Image tags no longer cover the picture: a signed book hides them, and the book and quill fades them to a faint trace you can still find with the cursor.
> - The image controls no longer cover Stendhal's formatting toolbar. They moved from the bottom edge to a panel beside the book, in the first spot free of other buttons; only a window too narrow for that keeps the old bottom rows.

## What the in-game test of 1.3.0.2 found

| Finding | Cause |
|---|---|
| The book and quill opened without a crash | The 1.3.0.0 Stendhal fix works in game ([[Stendhal Compatibility]]). |
| Tag text drawn over the picture, in the editor and the reader | Since the 26.x port images are drawn under the text; the old 1.20 to 1.21 code drew editor text at 25 % alpha. |
| ImagineBook's two rows of controls covered Stendhal's formatting toolbar | Stendhal places its toolbar and symbol buttons centred from `y = height - 50` down (read from its bytecode with `javap`), where ImagineBook's rows were. Its book actions are a column top left, page actions plus Done and Sign a column top right. |

## Fix

### Tags

- Reader: `BookScreenMixin.imaginebook$hideTags` strips tags from the page component in `BookViewScreen.visitText`, keeping its styles (`ImageTags.strip`).
- Editor: `MultiLineEditBoxMixin` draws tag text at about 15 % alpha through three `@WrapOperation` hooks on `GuiGraphicsExtractor.text` in `MultiLineEditBox.extractContents` (ordinals 0, 1, 2). Line begin and end are recorded from `StringView.beginIndex()` and `endIndex()`, because `StringView` is package-private in 26.3.
- Why this way and not hidden in the editor: [[Fade tags in the editor, hide them in the reader]].

### Controls

- `util/ControlPanelLayout` places a 200 px wide, 5-row panel in the first free spot left of the book, then right, clear of every widget and of the bottom band. The old bottom rows remain only as a fallback for narrow windows. Details in [[Stendhal Compatibility#Layout and the bottom band]].

### Build

- MixinExtras 0.5.5 comes nested in Fabric Loader 0.20.1. `tools/build_local.py` extracts it for the local build, and `build.gradle` has it `compileOnly` ([[Module Layout#MixinExtras]]).

## Verification

- 39 JUnit tests and 13 Python tests pass. New JUnit classes: `ImageTagsTest`, `ControlPanelLayoutTest`.
- `tools/mixin_smoke.py` passed with Stendhal.
- Not yet verified in game.
